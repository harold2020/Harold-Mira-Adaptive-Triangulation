# Harold and Mira — Adaptive Triangulation

A free educational driving simulation built by Harold and Mira (ChatGPT).

## Run the program

Download this repository using Code → Download ZIP.
Extract the ZIP, then open Harolds_Adaptive_Triangulation.html
in a modern desktop browser.

No installation or internet connection is needed to run it.

## Features

- One car with up to 1,000 simulated sensing rays.
- Nearby walls receive greater avoidance priority.
- Steering and speed account for clearance and handling limits.
- Save-state retries retain rule-based adjustments after failures.
- Three track layout families with reproducible seeds.
- A six-track comparison of checkpoint retries and full restarts.

## Experiment

Change the track, speed, grip, and sensing-ray count.
Watch the car's decisions, then inspect and modify the source.

## Current scope

This is a simplified 2D HTML/JavaScript simulation with static
walls and perfect simulated range measurements. It does not
establish real-world driving safety.

Human racing and controller support are planned for later.
